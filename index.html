Download & run

Start with the
toolkit.

Clone the project, create a clean Python environment, then use the CLI commands already documented in the repository.

Quick start
# clone
git clone YOUR_GITHUB_REPOSITORY_URL.git
cd netscope

# install locally
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
Useful commands
# verify
python3 -m unittest discover -v

# inspect risk
python3 -m netscope.cli risk CVE-2025-0001 --cvss 9.8 --epss 0.9 --kev

# inventory + topology
python3 -m netscope.cli inventory scan.json --db netscope.db
python3 -m netscope.cli topology scan.json > topology.json

! Only use NetScope against systems and ranges for which you have explicit authorization.
